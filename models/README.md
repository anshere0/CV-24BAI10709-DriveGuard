# Models Directory

This directory should contain the pre-trained weights for the computer vision models used in the DriveGuard pipeline.

## Required Models

1. **YOLOv8 Nano**: `yolov8n.pt`
   - Download from Ultralytics: `https://github.com/ultralytics/assets/releases/download/v0.0.0/yolov8n.pt`
   
2. **MediaPipe Face Landmarker**: `face_landmarker.task`
   - Download from Google: `https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task`

Place these files directly in this directory.
